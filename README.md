## 📋 Descripción del Proyecto

Este repositorio reúne los documentos estratégicos y los planes de ejecución para la plataforma de **e-commerce de GalaxGadgets**. Cada propuesta busca optimizar la estructura del negocio, la experiencia del usuario y la gestión operativa.
